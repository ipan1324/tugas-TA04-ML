Arsitektur Long Short-Term Memory (LSTM) untuk Pemodelan Data Sekuensial

Tinjauan komprehensif mengenai perumusan matematis, pra-pemrosesan data time series, serta alur kerja rekayasa model deep learning pada proyek AeroCast LSTM.

Perumusan Masalah & Justifikasi Pemilihan Kasus

Industri transportasi penerbangan internasional beroperasi dalam dinamika pasar yang sangat dipengaruhi oleh tren jangka panjang (pertumbuhan ekonomi dan ekspansi armada) serta fluktuasi musiman yang berulang setiap tahun (liburan sekolah dan musim panas). Ketidaktepatan peramalan jumlah penumpang dapat menimbulkan kerugian operasional masif, mulai dari kelebihan kapasitas kursi (excess capacity) hingga kekurangan armada dan awak kabin di rute padat.

Dataset AirPassengers merekam jumlah penumpang bulanan dari Januari 1949 hingga Desember 1960 (144 observasi), yang menjadi tolak ukur (benchmark) ideal dalam mengevaluasi kemampuan algoritma deep learning dalam memodelkan pola non-linear dan musiman majemuk secara simultan.

Mekanisme Arsitektur LSTM

Recurrent Neural Network (RNN) konvensional mengalami masalah vanishing/exploding gradient saat memproses sekuens data yang panjang. LSTM mengatasi keterbatasan ini melalui struktur sel khusus yang dikendalikan oleh tiga gerbang (*gates*):

Forget Gate ($f_t$)

Menentukan informasi masa lalu mana dari cell state sebelumnya ($C_{t-1}$) yang harus dibuang atau dipertahankan:
f_t = σ(W_f · [h_{t-1}, x_t] + b_f)

Input Gate ($i_t$) & Candidate ($\tilde{C}_t$)

Menentukan informasi baru mana yang akan disimpan ke dalam cell state:
i_t = σ(W_i · [h_{t-1}, x_t] + b_i)
C̃_t = tanh(W_c · [h_{t-1}, x_t] + b_c)

Output Gate ($o_t$) & Hidden State ($h_t$)

Menentukan nilai keluaran tersembunyi yang akan diteruskan ke langkah waktu berikutnya:
o_t = σ(W_o · [h_{t-1}, x_t] + b_o)
h_t = o_t * tanh(C_t)

Alur Pra-Pemrosesan: Scaling & Windowing

  1. Normalisasi Skala (MinMaxScaler): Mengubah rentang fitur target ke interval $[0, 1]$ menggunakan persamaan: x_norm = (x - x_min) / (x_max - x_min). Hal ini penting untuk menstabilkan fungsi aktivasi non-linier tanh dan mencegah dominasi nilai ekstrem pada gradien bobot.
  2. Transformasi Sekuens (Sliding Window): Dengan ukuran jendela look-back $T = 12$ bulan, deret $x_1, x_2, \dots, x_{144}$ dipetakan menjadi pasangan input-output: X_i = [x_i, x_{i+1}, \dots, x_{i+11}] dan target y_i = x_{i+12}.
  3. Reshaping Tensor 3D: Keras LSTM memerlukan format input 3 dimensi berukuran (samples, timesteps, features) = (105, 12, 1) untuk data latih dan (27, 12, 1) untuk data uji.

Metrik Evaluasi Kinerja

Metrik Formula Matematis Hasil Data Uji (Test Set) Interpretasi Praktis
RMSE $$\sqrt{\frac{1}{n} \sum (y_i - \hat{y}_i)^2}$$ {{ metrics.test_rmse }} Memberikan penalti lebih tinggi terhadap kesalahan deviasi besar (satuan: ribuan penumpang).
MAE $$\frac{1}{n} \sum |y_i - \hat{y}_i|$$ {{ metrics.test_mae }} Rata-rata kesalahan absolut secara riil terhadap jumlah penumpang aktual.
MAPE $$\frac{1}{n} \sum |\frac{y_i - \hat{y}_i}{y_i}| \times 100\%$$ {{ metrics.test_mape }}% Rasio deviasi persentase kesalahan; di bawah 10% menandakan akurasi sangat presisi.
$R^2$ Score $$1 - \frac{\sum (y_i - \hat{y}_i)^2}{\sum (y_i - \bar{y})^2}$$ {{ metrics.test_r2 }} Model mampu menjelaskan 80.9% variansi pola data uji yang belum pernah dilihat sebelumnya.
